# Ashgrave

An isometric action RPG in the spirit of Diablo 1, for the browser. Co-op for 2–4 players over peer-to-peer.

Play: https://classicd2.github.io/ashgrave/

- `index.html` is the built game (one self-contained file).
- `src/` holds the source: `data.js` (game data), `engine.js` (simulation), `client.js` (rendering and UI).
- `python3 build.py` rebuilds `dist/ashgrave.html`.
